# Lauren's Cafe & Bookstore #

## Project Overview ##
This project was an accumulation of several assignments over several weeks that kept adding onto each other. In this assignment I created a website for a fake business of my choice, three of my images are 
AI generated images, and I built out the filtering and search feature to be more complex.

## Tech Stack ##
1. HTML
2. CSS
3. JavaScript
